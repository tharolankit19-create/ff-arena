# FF Arena Mobile (React Native + Expo)

Scaffolded starter based on the web demo logic.

## Setup
1. cd mobile
2. npm install
3. npx expo start

## Features to implement from demo
- All screens with shared state (balance, tournaments, etc.)
- Squad creation modal
- In-app chat (Socket.io or Firebase)
- AI OCR for screenshot upload (integrate Vision or Tesseract)
- Live bracket view (react-native-svg or custom)

Use the same data models and API calls as the web version.
